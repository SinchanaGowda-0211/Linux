# Linux Basic Commands

## pwd
Shows the current working directory.

```bash
pwd
```

## ls
Lists files and directories.

```bash
ls
ls -l
ls -a
```

## cd
Changes directory.

```bash
cd Documents
cd ..
cd ~
```

## mkdir
Creates a new directory.

```bash
mkdir LinuxPractice
```

## touch
Creates a new file.

```bash
touch notes.txt
```

## cp
Copies files.

```bash
cp file1.txt backup.txt
```

## mv
Moves or renames files.

```bash
mv old.txt new.txt
```

## rm
Deletes files and folders.

```bash
rm file.txt
rm -r folder
```
